ใส่ Remark ใน PDF

เลือก PDF → เขียน remark → คลิกพื้นที่ว่างบนหน้าเอกสาร → Run รับ ZIP

เพิ่มทีละไฟล์หรือพร้อมกันได้ · ไม่เกิน 20 MB ต่อไฟล์ / รวม 80 MB · ประมวลผลในเครื่อง ไม่อัปโหลดเอกสาร
